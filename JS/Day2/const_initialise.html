JavaScript Data Types

String

Stores text values.

Example: "Hello"

Number

Stores numeric values.

Example: 100

Boolean

Stores true or false.

Example: true

Undefined

A variable declared without a value.

Example: let age;

Null

Represents no value.

Example: let user = null;

BigInt

Stores very large numbers.

Example: 12345678901234567890n

Symbol

Creates unique values.

Example: Symbol("id")

Object

Stores data in key-value pairs.

Example: { name: "John" }
