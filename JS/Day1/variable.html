Task 2 Definitions

1.What is variable?

A variable is like a container that holds a value and that value can change.Three keywords are used for it var,let,const.

2.What is declaration?

A declaration means creating a variable and giving it a name.

Example: let userName;

3.What is initialization ?

Initialization is the process of giving a variable its initial value or state before it is used.

Example: const userName="Sangeetha";

4.3 types of keywords

  1. var
  2. let
  3. const

5.what is compiler in js and its name ?

A compiler is a program that converts code into machine code so the computer can understand it.V8 Engine is present in the browser.

6.what is printing statement?

A printing statement is a command used to show output on the screen.

Example: console.log , alert()
