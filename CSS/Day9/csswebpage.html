1. What is CSS?

CSS stands for Cascading Style Sheets.It is used to design webpage and layout and style.CSS helps for making a webpage looking good and it is userfriendly design.Basically layout is a design of your webpage . It decides which content in which place to show on your screen.

Why CSS is Used

  • Add colors and fonts
  • Create layouts
  • Improve user interface
  • Make websites responsive
  • Add transition and effects

Basic CSS Syntax

p {
  color: blue;
  font-size: 20px;
}

Here:

  • p → Selector
  • color → Property
  • blue → Value

2. Types of CSS

Inline CSS

Inline CSS is written inside HTML element using style attribute.

<p style="color:red">Hello</p>

Inline CSS Example

Internal CSS

Internal CSS is written inside style tag in head section.

<style> p{ color:blue; } </style>

Internal CSS Example

External CSS

External CSS is written in separate .css file and linked to HTML.

<link rel="stylesheet" href="style.css">

External CSS Example

3. CSS Selectors

Selectors target HTML elements.

Universal Selector *

Selects all elements.

*{ 
          margin:0;
          padding:0;
          box-sizing:border-box }

Element Selector

p{ color:blue; }
Element Selector Output

Class Selector

.box{ background:pink; }
Class Selector Output

ID Selector

#box{ color:red; }
ID Selector Output

Group Selector

Applies same style to multiple elements.

h1,h2,p{ color:green; }

Descendant Selector

div p{ color:purple; }

Descendant Selector Example

Attribute Selector

input[type="text"]

4. CSS Specificity

Specificity decides which CSS style gets highest priority when multiple styles target same element.

Priority Order

  • Inline CSS → Highest
  • ID Selector
  • Class / Attribute / Pseudo-class
  • Element Selector → Lowest
#box{ color:red; } .box{ color:blue; }

ID wins over Class

5. CSS Box Model

Every HTML element is treated as a box. Box model contains:

  • Content
  • Padding
  • Border
  • Margin

Content

Actual text or image inside element.

Padding

Space between content and border.

Border

Line surrounding padding and content.

Margin

Outer space outside border.

padding:20px; border:5px solid blue; margin:20px;
Box Model Example

  • display:flex
  • justify-content
  • align-items
  • flex-direction
  • gap
